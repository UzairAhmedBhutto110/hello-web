3. Find one request that is not 200. What status is it, and what do you think happened?
Request: www.wikipedia.org

Status: 304 (Not Modified)

What happened: A 304 status code means your browser sent a conditional request to the server asking if the main web page had changed since it was last downloaded. The server responded that nothing had changed, so the browser reused its locally cached copy instead of sending a fresh copy across the network.

Why we refuse file://:

We avoid file:// in this course because it bypasses standard HTTP security rules, blocks cross-origin requests (CORS), and does not simulate how a real web server serves files over the internet.

DevTools habit:

Moving forward, I will keep the DevTools Console open at all times while coding to immediately spot syntax errors and broken link warnings.
